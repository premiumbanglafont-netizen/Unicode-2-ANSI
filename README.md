An elegant, fast, and light-weight web-based tool to convert **Unicode Bangla** text (Avro / Web format) into **Bijoy ANSI** text format for seamless use with **SutonnMJ** fonts in Adobe Photoshop, Illustrator, and MS Word.

## ✨ Key Features

* ⚡ **Real-Time Conversion:** Converts text instantly as you type or paste.
* 🔤 **Smart Vowel & Juktoborno Handling:** Properly reorders Kar-signs (ে, ৈ, ি) and complex Bengali ligatures for Bijoy ANSI output.
* 📋 **One-Click Copy:** Easily copy the converted ANSI text to your clipboard.
* 📱 **Fully Responsive:** Works smoothly on Desktop, Tablet, and Mobile browsers.
* 🎨 **Clean UI:** Simple, modern, and user-friendly user interface.

---

## 🛠️ How to Use

| Step | Action |
| :--- | :--- |
| **1** | Open the converter in your web browser. |
| **2** | Paste or type your **Unicode Bangla** text in the left input box. |
| **3** | Click **"Copy ANSI Text"** button. |
| **4** | Paste the copied text into **Photoshop / MS Word / Illustrator**. |
| **5** | Select **`SutonnMJ`** as your font to view the correct Bangla text. |
